# Password Reset

If a user reports that a password reset link expires immediately or does
not work:

1. Confirm the link was used within 15 minutes of being issued — links
   expire after that window for security reasons.
2. Check that the user is not opening the link in a different browser or
   private/incognito session than the one they requested it from.
3. Ask the user to clear cookies for the site, or try a different browser,
   then request a new reset link.
4. If the issue persists after a fresh link and browser, escalate to
   the identity-support team with the account email and a timestamp of
   the failed attempts.

Do not manually reset a password on a user's behalf without verifying
their identity through the standard two-factor verification process.
